🐾 Happy Paws Veterinary Ledger

Description:

Happy Paws Veterinary Ledger is a Java console application designed for a veterinary secretary to manage financial transactions, customer profiles, and pet appointments.

The program allows users to:

Add deposits and payments

View transactions and financial reports

Search transactions by vendor, date, or amount

Register pet owners and their pets

View and search customer profiles

Schedule, view, search, and cancel appointments

Save information in CSV files

Pets must have a registered customer profile before an appointment can be scheduled.

How to Run the Project

Download or clone the project from GitHub.

Open the project folder in IntelliJ IDEA.

Make sure the Java SDK is configured and Maven dependencies are loaded.

Navigate to src/main/java/org/example/Main.java.

Click the green Run button next to the main() method.

Follow the menu options in the console to use the application.
